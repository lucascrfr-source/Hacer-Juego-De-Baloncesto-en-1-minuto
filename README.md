# Hacer-Juego-De-Baloncesto-en-1-minuto
Crea un juego de baloncesto en Roblox Studio en 1 minuto. Incluye una cancha 3D, balón con física realista, lanzamientos, encestes, puntuación y partidas de 60 segundos. Diseña una interfaz moderna con iconos 3D brillantes, sombras y animaciones. Todo debe ser funcional y compatible con PC y móvil.
